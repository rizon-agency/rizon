## Ändern Sie die Aufgabe, bevor Sie eine Kamera kaufen

Die Prüfung mit dem größten Schutz gegen Täuschung ist nicht die mit der meisten Überwachung. Es ist jene, bei der das Kopieren einer Antwort nichts hilft, weil die Aufgabe etwas verlangt, das Lernende nur durch eigene Arbeit erstellen können. Gestalten Sie zuerst die Frage neu. Setzen Sie Überwachung zuletzt ein, wenn überhaupt.

Proctoring-Tools vermitteln ein Gefühl von Kontrolle, bis sie umgangen werden. Plattformen, die Prüfungen gut gestalten, investieren stattdessen in das Design. „Betrugssicher machen“ ist keine Funktion, die man installiert. Es ist eine Reihe von Entscheidungen über die Aufgabe.

## Was eine Aufgabe gegen Kopieren schützt

- **Fragen Sie nach Anwendung, nicht nach Erinnerung.** Eine Frage mit einer nachschlagbaren Antwort lädt zum Betrügen ein. „Erklären Sie, warum dieser Ansatz für diesen Datensatz scheitert“ hat keinen Lösungsschlüssel zum Einfügen.
- **Machen Sie sie persönlich für die Arbeit.** Binden Sie die Aufgabe an ein früheres Projekt, Daten oder eine Entscheidung der lernenden Person. Eine Antwort, die von der eigenen Vorarbeit abhängt, lässt sich nicht kopieren.
- **Zufällig aus einer echten Bank ziehen.** Eine Fragenbank hilft nur, wenn Varianten wirklich unterschiedliche Probleme sind, nicht dieselbe Frage mit anderen Zahlen. Geänderte Zahlen bremsen; andere Probleme sind eine Wand.
- **Bewerten Sie den Prozess, nicht nur das Ergebnis.** Eine kurze Reflexion darüber, *wie* jemand dorthin gelangte, oder eine gestufte Abgabe ist weit schwerer zu fälschen als eine Endantwort.
- **Nutzen Sie Zeit bewusst.** Ein enger Timer bei einer Erinnerungsprüfung belohnt vor allem jene mit offenem Lösungsschlüssel. Ein großzügiges Zeitfenster für eine angewandte Aufgabe belohnt echte Beschäftigung.

| Instinkt | Was er wirklich bringt | Besserer Schritt |
| --- | --- | --- |
| Proctoring hinzufügen | Abschreckung bis zur Umgehung | Aufgabe so gestalten, dass sie nicht kopierbar ist |
| Fragenreihenfolge mischen | Minuten Reibung | Bank wirklich unterschiedlicher Probleme |
| Timer verkürzen | Druck auf alle | Zeit auf Anwendung statt Erinnerung verwenden |
| Browser sperren | Ein Wettrüsten | Prozess neben dem Ergebnis bewerten |

## Die ehrliche Grenze

Sie können Betrug nicht unmöglich machen, und eine gut gestaltete Aufgabe behauptet das auch nicht. Ein entschlossener Lernender mit genügend Zeit kann weiterhin Hilfe bekommen. Gutes Design verändert jedoch die Ökonomie: Es macht Täuschen schwerer als die Arbeit selbst und bestraft nicht länger die ehrliche Mehrheit für die Handlungen einiger weniger. Das ist ein besseres, erreichbares Ziel.
