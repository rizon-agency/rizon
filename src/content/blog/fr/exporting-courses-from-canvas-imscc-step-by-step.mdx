## Ce que vous donne réellement un fichier IMSCC

L’export d’un cours Canvas produit un fichier IMSCC. C’est un moyen fiable de déplacer le *contenu* d’un cours. L’erreur consiste à le prendre pour une sauvegarde complète. Ce n’en est pas une. Les remises des étudiants, les notes et certains réglages d’outils externes ne se trouvent pas dans ce paquet. Le découvrir après le basculement gâche vite une journée.

IMSCC signifie IMS Common Cartridge. Voyez-le comme le programme et les ressources : pages, définitions de devoirs, questions de quiz, fichiers, organisation des modules. Ce qu’il laisse sur place, c’est tout ce qui s’est produit dans le cours, les traces des personnes, ainsi que les connexions avec les autres systèmes.

## Les étapes, avec ce qui manque à chaque fois

1. **Exportez le cours.** Dans le cours, ouvrez Paramètres → Exporter le contenu du cours → Cours. Vous obtenez un fichier `.imscc` qui contient la structure et les ressources.
2. **Exportez les notes séparément.** Le carnet de notes se télécharge en CSV depuis la page Notes. L’IMSCC ne le contient pas. Si un relevé de validation compte encore dans un an, c’est ce fichier qu’il ne faut surtout pas perdre.
3. **Recensez vos outils externes.** Les emplacements LTI et leurs configurations ne sont pas garantis dans le cartridge. Notez chaque outil, son emplacement et ses clés avant de modifier quoi que ce soit.
4. **Prévoyez les remises et les interactions.** Les fichiers déposés par les étudiants, les messages de discussion et les tentatives de quiz ne sont pas dans l’IMSCC. S’il vous les faut, prévoyez un export administrateur ou une demande de données distincte.

La documentation de Canvas précise qu’un paquet d’export de cours n’inclut pas les données propres aux étudiants, comme les remises et les interactions, et que les notes se sauvegardent séparément. Considérez cela comme le fonctionnement du format, pas comme un défaut à contourner. ([Documentation d’export de cours d’Instructure](https://community.canvaslms.com/t5/Instructor-Guide/How-do-I-export-a-Canvas-course/ta-p/785))

| Élément | Dans l’IMSCC ? | Comment il se déplace réellement |
| --- | --- | --- |
| Pages, devoirs, questions de quiz, fichiers | Oui | Le cartridge |
| Structure des modules et du cours | Oui | Le cartridge |
| Notes et carnet de notes | Non | Export CSV depuis Notes |
| Remises des étudiants et messages de discussion | Non | Export administrateur ou demande de données |
| Configuration et clés des outils LTI | Pas de façon fiable | Nouvel enregistrement sur la plateforme cible |

## Testez de nouveau les lancements, ne les supposez pas

Les outils externes sont souvent sous-estimés. Un outil LTI qui fonctionne dans Canvas repose sur des clés, un emplacement et un contrat de remontée des notes. Après import du cartridge, sa définition peut se retrouver sous forme de lien cassé sans identifiants valides. Chaque intégration a besoin d’un nouveau test de lancement et, lorsqu’elle renvoie des notes, d’un test de remontée. Ce sont deux contrôles différents. Oublier le second est une bonne façon de commencer un semestre avec des notes qui n’arrivent nulle part.

Si la maîtrise des données étudiantes explique votre départ, dites-le clairement.
