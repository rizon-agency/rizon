6. HOW TO ADD A POST (wiring checklist, learned from the codebase)
==================================================================
MDX files have NO frontmatter. Metadata lives in src/lib/posts.ts.
To add an English post you must touch 5 places:
  1. Cover asset: src/assets/blog/<name>.svg  (dark house style,
     1200x675, #101827 bg, "RIZON / <CATEGORY>" label). See
     wcag-accessibility-learning-platforms.svg as the template.
  2. src/content/blog/<slug>.mdx  (body only, starts with a ## H2,
     no H1, no frontmatter).
  3. src/lib/posts.ts:
     - import the cover at top
     - add a Post object to the `posts` array (newest first)
     - add an entry to the English `contentLoaders` map inside
       getPostContent()
  4. public/markdown/blog/<slug>.md  (mirror: # Title, > description,
     body with .md cross-links and /services /alternatives absolute
     links, then a "## Related reading" footer + All Rizon articles).
  5. public/markdown/blog/index.md  (add one line at top of Articles).
Post type fields: slug,title,description,date,readTime,category,
  coverImage,relatedServiceSlug,relatedAlternativeSlugs,
  relatedPostSlugs,authorSlug.
Valid service slugs: custom-lms-development, corporate-training-platform,
  course-platform-for-creators, school-student-portal-development.
Valid alternative slugs: canvas, moodle, teachable, thinkific, docebo,
  talentlms, blackboard.
Localization (de/fr/es) is OPTIONAL per post. If skipped, the post
  simply does not appear in those locales (getLocalesForPost filters
  it out). To localize later: add entries to localizedPostFields AND
  localizedPostLoaders in posts.ts, plus src/content/blog/<lang>/<slug>.mdx.
